NexusTech B2B Solutions
NexusTech B2B Solutions is a React-based promotional enterprise software website created as a WebProg final requirement. The project is designed as a conversion-focused promotional portal for business software, with interactive sections that present product value, configurable modules, and guided user actions.
Project Overview
This website was developed as an academic capstone-style project focused on UI/UX strategy for a B2B software promotional experience. Instead of functioning as a basic transactional store, the site is positioned as a lead-generation and product-education portal for enterprise software such as ERP, HRIS, and POS solutions
Objectives
•	Present enterprise software solutions in a modern and professional web interface.
•	Guide users from product discovery to meaningful actions such as demo requests or proposal export.
•	Demonstrate interactive React-based components suitable for a promotional SaaS website.
•	Apply UI/UX principles, modular component structure, and responsive presentation in a final WebProg project.
Main Features
•	Hero section with a clear call to action for prospects.
•	Interactive product showcase with live-style feature presentation.
•	ROI and cost calculator for estimating business value based on user input.
•	Interactive module configurator with selectable add-ons and dynamic updates.
•	Feature comparison presentation for modular ERP and related systems.
•	Client proof or testimonial section to build trust and credibility.
•	Sticky configuration bar to maintain a visible conversion path while scrolling.
•	Sandbox or demo request flow for lead capture.
Technologies Used
•	React JS for component-based interface development.
•	JavaScript for interactive calculations and dynamic state updates.
•	CSS for custom styling, dark-mode visuals, and responsive layout implementation.
Design Approach
The project follows a tech-inspired visual direction that uses dark surfaces, neon-accent styling, micro-interactions, and modular UI presentation. The overall design goal is to educate potential clients, highlight product capabilities, and support conversion within a few user interactions.
Academic Focus
The project aligns with three key evaluation areas described in the case study: UX conversion design, React component modularity, and state-management performance. These criteria shaped the structure of the interface, the use of interactive widgets, and the handling of dynamic updates across the site.
